Prerequisites:

  • Keplr browser extension installed
  • For predefined networks: Shardeum node running for selected network
  • For local/testnet/devnet: Use make start-network NETWORK=<network>
  • For custom networks: Ensure your chain is running and endpoints are accessible
  • API server enabled (check ports in network details above)
  • Access this page via http:// (not file://)

Troubleshooting:

  • If you get "failed to fetch", restart your network with the updated script
  • Make sure both RPC (26657) and API (1317) endpoints are running
  • Test endpoints: RPC Status | API Info
  • For custom networks: Verify your URLs are accessible and return valid responses
  • Ensure HTTPS is used for custom networks in production (HTTP only for local development)

Custom Network Guide:

Fields that typically change per Shardeum deployment:

  • Chain ID: Unique identifier (e.g., "shardeum-sphinx-1", "shardeum-betanet")
  • Chain Name: Display name (e.g., "Shardeum Sphinx", "Shardeum Betanet")
  • RPC URL: Tendermint RPC endpoint (port 26657)
  • REST URL: Cosmos SDK REST API endpoint (port 1317)
  • JSON-RPC URL: EVM JSON-RPC endpoint (port 8545, optional)

Shardeum standard values (pre-filled, rarely change):

  • Token Symbol: SHM (Shardeum standard)
  • Base Denom: ashm (atto-SHM, Shardeum standard)
  • Decimals: 18 (Shardeum standard)
  • Bech32 Prefix: shardeum (Shardeum standard)
  • EVM Chain ID: 8119 (Shardeum standard, optional for EVM features)
