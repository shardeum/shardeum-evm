Add Shardeum Local Network to Keplr

Network Details:
• Chain ID: shardeum-testnet
• RPC: http://127.0.0.1:26657
• Token: SHM (ashm)
• Decimals: 18

Prerequisites:

  • Keplr browser extension installed
  • Local Shardeum node running with: make start-network
  • API server enabled (ports 26657 for RPC, 1317 for API)
  • Access this page via http:// (not file://)

Troubleshooting:

  • If you get "failed to fetch", restart your network with the updated script
  • Make sure both RPC (26657) and API (1317) endpoints are running
  • Test endpoints: RPC Status | API Info
