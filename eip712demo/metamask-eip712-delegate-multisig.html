Shardeum EIP-712 Multisig & Delegate Demo

Each signer connects with MetaMask and signs the same EIP-712 payload for a Cosmos MsgDelegate. The JSON you download per signer is what the Go tool (broadcast-eip712-multisig) consumes.

1. Wallet
Connect an EVM wallet (MetaMask).
2. Transaction Parameters
These must be identical for all signers: same delegator (multisig), fee, gas, memo, account number, and sequence.
3. Sign & Export
Each signer should:
  1. Ensure the parameters above match the agreed values.
  2. Click Sign with MetaMask.
  3. Download the JSON file and send it to whoever runs the Go tool.
