📤 Broadcast & Verify Transaction

To broadcast your signed transaction:

  1. Save the signed transaction JSON to a file (e.g., signed-tx.json)
  2. Run the broadcast command: 
    ./build/broadcast-eip712 signed-tx.json --broadcast --node http://localhost:1317 --cosmos-chain-id shardeum_8117-1 --evm-chain-id 8117
  3. Verify the transaction:
    • Delegate: shardeumd query staking delegation [delegator] [validator] --node http://localhost:26657
    • Undelegate: shardeumd query staking unbonding-delegation [delegator] [validator] --node http://localhost:26657
    • Vote: curl http://localhost:1317/cosmos/gov/v1/proposals/[proposal_id]/votes/[voter_address]
